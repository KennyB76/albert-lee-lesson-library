Standing Waves on Strings & in Pipes:
Harmonics, Wavelengths & Frequencies

Student: Albert Lee Date: 2026-05-06
Standard: AP Physics 1 (2024 CED) — Unit 8: Mechanical Waves & Sound. SP 6.E: Boundary conditions of strings (fixed-fixed) and pipes (open-open, open-closed) determine allowed harmonics; relate wavelength, frequency, length, and wave speed via $v=f\lambda$.
EQUATION REFERENCE SHEET
Wave Speed $v = f\lambda$ $v$ = wave speed, $f$ = frequency, $\lambda$ = wavelength.
String
(both ends fixed)		 $\lambda_n = \dfrac{2L}{n}, \quad f_n = \dfrac{nv}{2L}$ $n = 1, 2, 3, \ldots$ — all harmonics allowed. Nodes at both ends.
Open pipe
(both ends open)		 $\lambda_n = \dfrac{2L}{n}, \quad f_n = \dfrac{nv}{2L}$ $n = 1, 2, 3, \ldots$ — same as string. Antinodes at both ends.
Closed pipe
(one end closed)		 $\lambda_n = \dfrac{4L}{n}, \quad f_n = \dfrac{nv}{4L}$ $n = 1, 3, 5, \ldots$ — odd harmonics only. Node at closed end, antinode at open end.
Fundamental $f_1$ (smallest $n$) Higher harmonics: $f_n = n\,f_1$ (string / open pipe), $f_n = n\,f_1$ for odd $n$ only (closed pipe).
Worked Example
Read carefully — the same logic applies to every problem below. Identify boundary type first, then pick the right formula.
Example — String fixed at both ends
A guitar string of length $L = 0.65~\text{m}$ is fixed at both ends. The wave speed on the string is $v = 260~\text{m/s}$.
(a) Find the fundamental frequency $f_1$.
(b) Find the frequency of the 3rd harmonic $f_3$.
(c) Find the wavelength $\lambda_3$ of the 3rd harmonic.
Solution.

Identify: String fixed at both ends $\Rightarrow$ use $f_n = \dfrac{nv}{2L}$ with $n=1,2,3,\ldots$

(a) $f_1 = \dfrac{(1)(260)}{2(0.65)} = \dfrac{260}{1.30} = 200~\text{Hz}$.

(b) $f_3 = 3\,f_1 = 3(200) = 600~\text{Hz}$.

(c) $\lambda_3 = \dfrac{2L}{n} = \dfrac{2(0.65)}{3} = \dfrac{1.30}{3} \approx 0.433~\text{m}$.

Check: $v = f_3\,\lambda_3 = (600)(0.433) \approx 260~\text{m/s}$. ✓

Practice Problems
Directions: Show all work in the space provided. State the boundary condition, write the relevant equation, then plug in. Round answers to 3 significant figures unless asked otherwise. Take the speed of sound in air to be $v = 343~\text{m/s}$ unless told otherwise.
1. A string of length $L = 1.20~\text{m}$ is fixed at both ends. The wave speed on the string is $v = 480~\text{m/s}$. Find the fundamental frequency $f_1$ and the wavelength $\lambda_1$.
2. The fundamental frequency of a string fixed at both ends is $f_1 = 220~\text{Hz}$. List the next three harmonic frequencies $f_2$, $f_3$, $f_4$.
3. An organ pipe is open at both ends and has length $L = 0.85~\text{m}$. Take $v = 343~\text{m/s}$. Find the fundamental frequency $f_1$ and the frequency of the 2nd harmonic $f_2$.
4. An organ pipe is closed at one end and open at the other, with length $L = 0.85~\text{m}$. Take $v = 343~\text{m/s}$. Find the fundamental frequency $f_1$ and the next allowed harmonic frequency.
5. Two pipes have the same length $L$. Pipe A is open at both ends; Pipe B is closed at one end. Show algebraically that $f_{1,A} = 2\,f_{1,B}$, and explain in one sentence why Pipe B has only odd harmonics.
6. A closed pipe (one end closed) produces a fundamental frequency of $f_1 = 196~\text{Hz}$ when $v = 343~\text{m/s}$. Find the length $L$ of the pipe and the wavelength $\lambda_1$.
7. A string fixed at both ends has length $L = 0.50~\text{m}$. Its 4th harmonic has frequency $f_4 = 880~\text{Hz}$. Find the wave speed $v$ on the string and the wavelength $\lambda_4$.
8. A closed pipe has length $L = 1.10~\text{m}$ and $v = 343~\text{m/s}$. List the first three allowed harmonic frequencies (from lowest to highest).
9. A guitar string of length $L = 0.64~\text{m}$ is tuned so that its fundamental is $f_1 = 330~\text{Hz}$ (high E). Find the wave speed $v$ on the string and the wavelength $\lambda_2$ of the 2nd harmonic.
10. A pipe of length $L$ is observed to resonate at frequencies $f = 250~\text{Hz}$ and $f = 750~\text{Hz}$, but not at $500~\text{Hz}$. Take $v = 343~\text{m/s}$.
(a) Is the pipe open at both ends, or closed at one end? Justify.
(b) Find the length $L$.
